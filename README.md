# se_project_news-explorer

A website that lets users search for news articles by keyword and save selected articles to a separate page.

## Functionality

- **News Search**: Fetches real-time news articles from News API based on user-entered keywords.
- **Saved Articles Page**: Allows users to save and remove articles
- **Simulated Authentication**: Uses React state and context to simulate user login and protected routes.
- **Interactive Article Cards**: Articles are displayed as reusable card components with save and delete actions.
- **Responsive Design**: Layout and UI elements scale across desktop, tablet, and mobile screen sizes.

## Tech Stack

- **React** with functional components and hooks
- **React Router** for client-side routing and protected routes
- **Context API** for managing simulated authentication state
- **Deployment** via GitHub Pages
- **Vite** for fast development and optimized builds
- **Fetch API** for asynchronous news data retrieval
- **State-driven rendering** for dynamic UI updates
