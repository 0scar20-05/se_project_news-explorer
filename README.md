# se_project_news-explorer

Full-stack news search application allowing users to find articles by keyword and save selected content to a dedicated page.

## Functionality

- **News Search**: Fetches real-time articles from a third-party News API based on user-entered keywords.
- **Saved Articles Page**: Enables users to save and remove articles with state-driven UI updates.
- **Simulated Authentication**: Uses React Context and state to simulate user login and protected routes.
- **Reusable Article Cards**: Displays articles as modular card components with save and delete actions.
- **Responsive Design**: Layout adapts across desktop, tablet, and mobile screen sizes.

## Tech Stack

- **React** with functional components and hooks
- **React Router** for client-side routing and protected routes
- **Context API** for managing simulated authentication state
- **Fetch API** for asynchronous news data retrieval
- **Vite** for fast development and optimized builds
- **Deployment** via GitHub Pages
- **State-driven rendering** for dynamic UI updates
